|---|---|
| [**Flappy Bird from raw pixels**](https://github.com/Tewf/Side_Projects/tree/main/Flappy_Bird_CNN) | A 3-layer CNN trained by REINFORCE policy gradient on 84×84 grayscale frames — no game state, just what the screen shows. *PyTorch, Pygame, Gymnasium* |
| [**Gröbner-basis 3-SAT solver**](https://github.com/Tewf/Side_Projects/tree/main/Groebner_Basis_SAT_Solver) | Encodes clauses as polynomials in GF(2)[x₁…xₙ]/(xᵢ²−xᵢ), propagates by triangular elimination, then branches.
